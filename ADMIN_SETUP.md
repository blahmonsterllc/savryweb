# Admin setup

The Google sign-in this file used to describe is retired.

Admins sign in at `/admin` through Cloudflare Access, then with their own Savry
account (Apple or email) on the admin list, then with a code from an authenticator
app. Everything they do is recorded at `/admin/activity`.

Setup, recovery, and the activity log: **[docs/admin-security.md](docs/admin-security.md)**.
